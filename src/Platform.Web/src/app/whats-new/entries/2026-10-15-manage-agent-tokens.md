---
title: See and revoke anyone's agent tokens
date: 2026-10-15
audience: admins
link: /settings/agent-tokens
linkLabel: Settings → Agent Tokens
---
**Settings → Agent Tokens** lists every personal access token together with its owner. You can revoke a single token or all of one person's tokens, and if a token has leaked you can paste it into the search to find it. Tokens also stop working on their own once their owner's account is disabled.
