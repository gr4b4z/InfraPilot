---
title: Make catalog approval depend on what's requested
date: 2026-11-06
audience: admins
link: /settings/catalog
linkLabel: Settings → Service Catalog
---
In **Settings → Service Catalog**, an item can now have approval rules: for example, no approval for dev and test, but approval from a named group for staging. Each request shows which rule applied.

An item's pipeline can also be told who raised the request and the request's ID, so it can send the result straight to that person.
